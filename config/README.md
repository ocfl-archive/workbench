# Workbench Configurations (`config/`)

This directory contains configuration templates and default settings used by the Workbench suite.

---

### Files

- **`workbench.toml`:** Sample TOML configuration file specifying batch directories, `{batch}` path templates, and toolchain configurations (`gocfl`, `ona`).
